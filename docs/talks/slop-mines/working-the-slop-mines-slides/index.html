Private Proof / Public Signal

Zero-knowledge exploitability proofs

private exploit witness
  -> public vulnerable target
    -> ZK proof of impact
      -> auto triage score
        -> bounty escrow / disclosure path

prove impact, reveal later

zkbounty.org did not resolve here on 2026-06-27, so treat this as a concept hook. The point: automated triage needs to distinguish real exploitability from spam without forcing researchers to publish the full exploit immediately. A zero-knowledge proof could attest that a private witness triggers a public vulnerable condition, enabling scoring, escrow, duplicate detection, and coordinated disclosure before revealing the exploit details.
