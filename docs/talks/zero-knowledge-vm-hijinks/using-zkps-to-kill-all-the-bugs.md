# Using ZKPs to Kill *all* the Bugs

Delivered at ToorCamp 2024 on June 28, 2024, from 2:30–2:50 PM Pacific in the Prime Dome.

This 20-minute talk explores how zero-knowledge proofs can improve software security, from the capabilities available to builders to proving that a vulnerability can be exploited without revealing the exploit itself.

## Highlights

- Proofs of exploitability for automated bug bounty triage.
- Economically backed claims about software security.
- Automated security metrics across the software supply chain.
